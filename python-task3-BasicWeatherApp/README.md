# Basic Weather App

A command-line weather application built with Python that fetches real-time data using the OpenWeatherMap API.

## Features
* Fetches live weather conditions for any user-specified city.
* Displays temperature (Celsius and Fahrenheit), humidity, wind speed, and weather description.
* Includes robust error handling for invalid API keys, network issues, and unrecognized city names.
* Prevents empty inputs through input validation.

## Tech Stack
* Python 3
* `requests` library
* OpenWeatherMap API
